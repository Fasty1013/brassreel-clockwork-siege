# BRASSREEL: Clockwork Siege — заметки для Claude Code

Стимпанк-рогалик: слот-машина призывает роботов, роботы защищают котёл от 30 волн.
Подробное описание правил — `docs/GAME_INFO.md`, журнал работ — `docs/WORK_LOG.md`,
баланс и симулятор — `docs/BALANCE.md` (раздел 7).

Играть: https://fasty1013.github.io/brassreel-clockwork-siege/ (обновляется при отправке в `main`).

---

## 1. Ход игры

1. **Подготовка:** прокрутки барабанов (3 бесплатные, дальше за пар и жар), удержание и сдвиг барабанов.
   Тройка в линию призывает робота в резерв (10 мест).
2. **Расстановка:** перетаскивание на поле 8×5; лимит роботов 5, древо навыков и гаджет поднимают его.
   Слияние: два робота одной линейки и уровня → уровень +1 (до 5★), эволюция на 3★ и 5★.
3. **Бой:** автобой, враги идут справа к котлу; у каждого робота работает своя черта (`src/data/quirks.ts`).
4. **Мастерская:** 3 случайных гаджета (улучшения и расходники), редактор барабанов, древо навыков (T).

## 2. Устройство кода

| Папка | Что там |
|---|---|
| `src/core/` | вся логика без графики, детерминирована зерном; изменения — через `reducer.ts` |
| `src/core/combat/combatEngine.ts` | бой: атаки, черты роботов, статусы, клапан |
| `src/core/gadgets/gadgets.ts` | гаджеты: витрина, цены, эффекты |
| `src/core/skills/skills.ts` | древо навыков и лимит поля |
| `src/core/campaign/campaign.ts` | кампания: части Регулятора, сцены, угрозы (данные в `src/data/story.ts`) |
| `src/data/` | числа: `balance.ts` (в т.ч. рост врагов `ENEMY_SCALE_ANCHORS`), роботы, враги, черты, тексты `i18n` |
| `src/art/forge/` | генератор пиксельных фигурок и значков |
| `src/art/ui/` | рамки и панели интерфейса (`UISkin.ts`, `frames.ts`) |
| `src/ui/`, `src/scenes/` | окна и сцены Phaser |
| `tools/sim/` | забеги ботами без графики; `VeteranBot` играет по текущим правилам |
| `tools/qa/` | скриншоты (`shot.ts`), листы спрайтов, проверка играбельности |

Шрифт интерфейса — Rubik (`@fontsource/rubik`, 500 и 700), подключается в `src/main.ts`,
все тексты проходят через `src/ui/TextStyles.ts`. Пиксельные шрифты не годятся: при окне меньше
1920×1080 игра уменьшается, и тонкие пиксельные буквы рвутся. В таком окне `main.ts` включает
сглаженное масштабирование холста, в полном размере — пиксельное.

## 3. Команды

```bash
npm install
npm test                 # тесты (Vitest)
npm run build            # сборка в dist/
npm run dev              # сервер разработки
npm run sim -- --runs 1000 --bot veteran --waves 30   # баланс: таблица по волнам
npm run build && CHROME_PATH=/путь/к/chrome npx tsx tools/qa/shot.ts out.png "<код>"
npm run build && CHROME_PATH=/путь/к/chrome npx tsx tools/qa/screens.ts shots 844 390 3   # экраны на телефоне
```

На Windows `BRASSREEL.exe` раздаёт папку `dist` и открывает игру окном браузера.

---

## 4. Правила работы

1. После изменений: `npm test` и `npx tsc --noEmit` без ошибок.
2. Меняете силу роботов, врагов или экономику — прогоните симулятор и обновите `docs/BALANCE.md`.
3. Графика процедурная: картинки рисуются кодом, внешних `.png` в игре нет.
4. Тексты для игрока — в `src/data/i18n/ru.json` и `en.json`; описание должно совпадать с тем, что делает код.
5. Отправка в `main` публикует игру (GitHub Actions, сначала прогоняются тесты).
