# Порядок: /qa-pass

Проверка перед выпуском или после крупной правки.

## Шаги

1. **Типы:** `npm run typecheck` — без ошибок. (Отдельного линтера в проекте нет.)
2. **Тесты:** `npm test`, с покрытием — `npm run test:coverage`. Все тесты `tests/` проходят.
3. **Детерминизм:** `tests/core/seedDeterminism.test.ts` — одно зерно дважды даёт тот же забег.
4. **Симулятор:** `npm run sim -- --runs 1000 --bot veteran --waves 30` — ни одной ошибки и ни одного
   зависшего боя; старые боты (`random`, `greedy`) — на падения при странной игре.
5. **Браузер** (после `npm run build`):
   - `npx tsx tools/qa/verifyPlayability.ts` — меню → барабаны → бой;
   - `npx tsx tools/qa/shot.ts out.png "<код>"` — скриншот нужного состояния; `SHOT_WIDTH`/`SHOT_HEIGHT` —
     окно другого размера; на Linux — `CHROME_PATH=/путь/к/chrome`;
   - вручную: меню → прокрутки → перетаскивание → бой → итог → мастерская → следующая волна;
     пауза через Esc и возврат; карта кампании (K); древо (T).
6. **Ошибки** — в `docs/BUGS.md`: где, что, как воспроизвести, важность.
