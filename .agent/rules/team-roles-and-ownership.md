# Роли и зоны ответственности

Проект ведёт команда агентов (и человек). У каждой роли своя зона файлов. Правку в чужой зоне сначала
записывают задачей в `docs/HANDOFF.md`.

## 1. Роли

| Роль | Чем занимается | Файлы |
|---|---|---|
| **Ведущий архитектор** | устройство кода, сборка, ревью, правила команды | `docs/ARCHITECTURE.md`, `.agent/**`, `package.json`, `tsconfig.json`, `vite.config.ts`, `vitest.config.ts`, `.github/**`, `launcher/**` |
| **Геймдизайнер** | правила и числа на бумаге, ветки роботов, ядра, гаджеты, сюжет | `docs/GDD.md`, `docs/GAME_INFO.md`, `src/data/story.ts` |
| **Разработчик логики** | барабаны, жар, слияние, экономика, гаджеты, навыки, ядра, кампания, архив, состояние | `src/core/**` кроме `combat/` и `waves/`; `tests/core/**`, `tests/meta/**` |
| **Разработчик боя** | бой: движение роботов и врагов, цели, черты, статусы, боссы, проверки ОТК | `src/core/combat/**`, `src/core/waves/**`, `tests/combat/**` |
| **Контент** | таблицы данных и схемы, тексты ru/en | `src/data/**` кроме `balance.ts` и `story.ts` |
| **Интерфейс** | сцены Phaser, окна, HUD, перетаскивание, подсказки | `src/scenes/**`, `src/ui/**`, `src/main.ts` |
| **Графика** | процедурные фигурки, фоны, рамки, эффекты, постановка прокрутки | `src/art/**`, `src/presentation/**`, `src/fx/**` |
| **Звук** | синтез звуков WebAudio | `src/audio/**`, `tests/audio/**` |
| **QA** | браузерные проверки, скриншоты, детерминизм, реестр ошибок | `tests/e2e/**`, `tools/qa/**`, `docs/BUGS.md` |
| **Баланс** | симулятор и боты, замеры, числа | `tools/sim/**`, `docs/BALANCE.md`, `src/data/balance.ts`, `docs/sim-reports/**` |

## 2. Правила

1. **Своя зона.** Нужна правка в чужой — задача в `docs/HANDOFF.md`.
2. **Логика без браузера.** `src/core` не импортирует Phaser и не трогает `window`/`document`
   (кроме проверенного доступа к `localStorage` в `core/meta`). Логика должна работать в Node.
3. **Только через команды.** Состояние забега меняет только `RunReducer.dispatch` (`src/core/state/reducer.ts`).
4. **Свои потоки случайности.** `reel`, `combat`, `loot`, `shop` из одного зерна; новый случайный выбор
   берёт поток своей системы.
5. **Проверки после каждой правки:**
   - `npm run typecheck` — без ошибок;
   - `npm test` — все тесты проходят;
   - менялась сила роботов, врагов или экономика — `npm run sim -- --runs 1000 --bot veteran --waves 30`
     и итог в `docs/BALANCE.md`.
6. **Тексты.** Новые строки для игрока — ключами в `src/data/i18n/ru.json` и `en.json`. Описание обязано
   совпадать с тем, что делает код. (В коде окон ещё много строк напрямую — `docs/BUGS.md` BUG-008; новых не добавлять.)
7. **Графика кодом.** Внешних `.png` и звуковых файлов в игре нет.
8. **Отправка в `main` публикует игру** (GitHub Actions: тесты → сборка → сайт).
